# PYlearn

Русскоязычный интерактивный сайт для практики основ Python. 40 задач в семи последовательных модулях: погружение в Python, простые типы данных и вычисления, ветвления, импортируемые типы данных, коллекции, итерации и циклы, функции и финальный анализатор данных.

В каждой задаче есть короткая теория, примеры, подсказка, решение и автоматические тесты. Python выполняется в отдельном Web Worker через Pyodide 0.28.3 (настоящий CPython / WebAssembly). Можно запускать код со своими входными данными, проверять решение и скачивать `.py`. Последующие задания открываются после успешной проверки предыдущих. Выполнение можно остановить; лимит одного запуска — 5 секунд, объём вывода ограничен.

Прогресс, очки опыта и черновики сохраняются в localStorage браузера. Экспорт и импорт JSON позволяют переносить их между устройствами. Учётная запись и серверная база данных не требуются. Проверка учебная: ответы и тесты доступны в исходниках и не предназначены для экзаменов.

## Локальный запуск

Потребуется Python 3. Из корня проекта:

```sh
python3 -m http.server 4173 --bind 127.0.0.1 --directory dist
```

Открыть `http://127.0.0.1:4173`. Через `file://` модули и Web Worker не загрузятся.

Node.js нужен только для проверок. Установка npm-зависимостей и сборка не нужны:

```sh
npm run check
```

Проверка выполняет все 40 эталонных решений, 8 регрессионных сценариев и перенос прогресса из первой версии через тот же Python-код, который используется внутри Worker. Она требует Node.js 22+ и Python 3; путь к Python можно указать переменной `PYTHON`.

## Размещение

Каталог `dist/` готов к любому статическому хостингу с HTTPS. Все пути относительные; маршруты используют URL hash, поэтому отдельные rewrite-правила не нужны.

Для первой загрузки Python нужен интернет: среда загружается с `cdn.jsdelivr.net/pyodide/v0.28.3/full/`. Шрифт Manrope загружается с Google Fonts; при его недоступности используются системные шрифты. Сам код пользователя не отправляется на сервер проверки. При настройке CSP разрешите эти источники и WebAssembly. Подробнее об исполнении: [Pyodide Web Worker](https://pyodide.org/en/0.28.3/usage/webworker.html).

## Файлы

- `dist/index.html`, `dist/styles.css` — адаптивный интерфейс.
- `dist/app.js` — навигация, редактор, прогресс и взаимодействие с Worker.
- `dist/data.js` — учебные модули, задания и тесты.
- `dist/progress.js` — прогресс, открытие задач и миграция прежних 30 заданий.
- `dist/themes.css`, `dist/preferences.js` — светлая/тёмная тема и управление приветствием.
- `dist/audio/welcome.mp3` — готовая озвучка приветствия.
- `dist/python-worker.js` — исполнение Python, ввод-вывод и проверка.
- `scripts/check-curriculum.mjs` — проверки программы курса и исполнителя.

Горячие клавиши: `/` — поиск, `Ctrl/⌘ + Enter` — проверка решения, `Tab` в редакторе — четыре пробела. После двоеточия редактор автоматически добавляет отступ.

## Тема и приветствие

Тёмная тема включена по умолчанию. Переключатель вверху сохраняет выбранную тему в браузере. При входе звучит «Быть программистом не так уж легко». Это низкая драматическая синтетическая озвучка, согласованная с заказчиком; оригинальные игровые реплики и клонирование актёрского голоса не используются. Аудиофайл включён в сайт и не требует внешнего TTS при воспроизведении.

Если браузер блокирует автозапуск, сайт показывает кнопку «Войти со звуком». Можно войти без звука и включить приветствие позже кнопкой громкости вверху. На странице нет микрофонных разрешений.

Прогресс прежней версии автоматически переносится: все решённые задачи и черновики сохраняются, а новые темы открываются по первой непройденной задаче. Поддерживается импорт файлов pylearn-v1 и pylearn-v2.
